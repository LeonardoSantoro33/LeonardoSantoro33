# Leonardo Santoro

BSc student in Computer and Automation Engineering at Sapienza University of Rome, working on interpretable learned sparse retrieval.

## Research
Supervised by Prof. Fabrizio Silvestri and Prof. Franco Maria Nardini. Manuscript in preparation.

- [splade-concept-model](https://github.com/LeonardoSantoro33/splade-concept-model): concept model g(x) = W·SPLADE(x) for sparse-to-dense retrieval, evaluated on MS MARCO and BEIR.
- [splare-lce](https://github.com/LeonardoSantoro33/splare-lce): training-free query expansion in the latent space of SPLARE, using a co-occurrence matrix of latents, evaluated on MS MARCO.

## Projects
- [splade-lens](https://github.com/LeonardoSantoro33/splade-lens): see which terms SPLADE adds to a query and a document, where each comes from, and what the score is made of. [Live demo](https://leonardosantoro33.github.io/splade-lens/)
